# Invertexto

Aplicativo desenvolvido em Flutter utilizando a API do Invertexto.

## 📱 Download

[⬇️ Baixar APK — Versão 1.0.0](../../releases/latest)

## Funcionalidades

- Conversão de números por extenso
- Busca de endereço por CEP
- Geração de pessoa
- Geração de código de barras
- Validação de e-mail
